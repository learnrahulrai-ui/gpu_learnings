04. SIMD and the while loop: 8 counts, 1 loop

Pencil. Paper. Every blank ____ is yours. Open CHECK only after you wrote a number.

Start from zero

Pages 01 to 03: each grid square (i, j) of the 256 x 256 output becomes a spot (cx, cy), and the count is how many passes of lines A to F happen before x2 + y2 goes above 4, capped at 1000. Each square has its own count, and the counts differ. The CPU in your machine (Ryzen 5 4600H, AVX2) has 256-bit registers. 256 bits / 32 bits per float = 8 floats per register, so one instruction does the same operation on 8 numbers. The lab asks for mandelbrot_cpu_vector: 8 neighbouring squares of one row in 8 lanes, one loop for all 8. This is the loop you ended with:

while (iter < max_iters) {
    __m256 mask = _mm256_cmp_ps(_mm256_add_ps(x2_vec, y2_vec), four, _CMP_LE_OQ);
    if (_mm256_testz_ps(mask, mask)) break;
    iters_vec = _mm256_sub_epi32(iters_vec, _mm256_castps_si256(mask));
    /* lines A to F, each one an 8-lane instruction */
    ++iter;
}

Where you got stuck

Step 2: the minus sign that counts up

32 bits all 1, read as a signed 32-bit integer, is -1 (two's complement: 0xFFFFFFFF = -1). _mm256_castps_si256 changes nothing in the bits; it only lets the next instruction read them as integers. _mm256_sub_epi32 then does lane-by-lane subtraction: count minus mask.

lane with Y:   count - (-1) = count + 1
lane with N:   count -  0   = count

The loop never asked "which lane finished". Each lane's own mask bit froze its own count.

Step 3: the lanes that keep calculating

After lane 6 fails the test (before pass 6), lines A to F still run on lane 6, because one instruction runs on all 8 lanes. Only its count is frozen. Check that a finished lane cannot come back to Y. Take the spot from page 02, step 2 (j = 255, cx = 0.490234), which stopped after 5 passes with x = 2.857909, x*x = 8.167644.

x = 8.657878    x*x = 74.958850   > 4   still N
Once above 4, the next value is larger again (it overflows to inf, then NaN;
_CMP_LE_OQ returns N for NaN). A frozen lane stays frozen.
