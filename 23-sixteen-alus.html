The story

Lecture 2 of MIT 6.S894 draws one box labelled Fetch & Decode above a long line of boxes labelled ALU 1, ALU 2 and so on to ALU 16 and beyond, each above its own box labelled State, and under all of them one wide box labelled Shared State. This way of executing, one instruction for many arithmetic circuits, is called SIMD, and the slide says it can be written into the instruction set, as in Intel's AVX and ARM's NEON, or be built invisibly into many GPUs.

The learner had already written AVX code: vectors of 8 floats in a 256-bit type, added pairwise by one instruction. The drawing still made no sense. If one core has 16 ALUs, can a program declare only 16 vector variables? Why 16, when an AVX add takes 8 pairs? And what is a state that each ALU owns, next to a state they all share?

The drawing counts something about one core. Is it how many numbers the core can hold, or how many it can work on in one tick of its clock?

In plain words

A processor core has a fixed number of arithmetic circuits, and that number says how many number operations can begin in one tick of its clock. It says nothing about how many numbers a program can keep. Those live in memory, and a small set of fast holding places inside the core keeps the ones in use right now; when there are more, the rest wait in memory and are fetched when needed.

For a manager: arithmetic circuits set peak speed and memory sets capacity; an estimate that mixes the two will be wrong on both.

The interviewer's next question

On Zen 2, a vector float add's result is ready 3 cycles after it begins, and 2 can begin per cycle. A loop adds a long array into independent __m256 sums. How many sums are needed to begin 2 adds in every cycle, and are the 16 register names enough?

CHECK 
Each sum's next add waits 3 cycles for its previous result; to begin 2 adds in each of
those 3 cycles, 2 * 3 = 6 independent sums are needed. 6 sums use 6 of the 16 names, so
none has to live in memory; 20 sums would add the loads and stores of L10 without
beginning more than 2 adds per cycle.
