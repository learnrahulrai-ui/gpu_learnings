Which index of C gets x

Topics: Lab 4, GPU chip. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

A kernel that computes a matrix gives each thread two numbers, x and y, and the code decides which index of the matrix each one becomes. Both choices give a correct result, so no check of the output tells them apart.

The question here: what in the numbering of threads and the layout of the matrix decides which index must take x?

Work it out

L01 NVIDIA's CUDA programming guide: in a block of sizes (Dx, Dy), the thread with numbers (x, y) has thread ID x + y * Dx; the hardware executes 32 threads of consecutive thread IDs with one common instruction, each thread with its own registers; the memory system serves the addresses of one instruction in pieces of 32 bytes, each beginning at a multiple of 32. The Lab 4 starter stores C(i, j) at c[i * size_j + j], with size_j = 3072 in its large test. from: the CUDA programming guide; the Lab 4 starter

L02 DO In a block of dim3(32, 8), the thread (5, 2) has ID ____ . Which of 32 and 8 never appears, and why? ____ . The 32 threads with IDs 64 to 95 have y = ____ and x = ____ . from: L01

CHECK 
5 + 2 * 32 = 69
8 never appears: the ID counts the threads before this one, and the lines after it do not
change that count
IDs 64 to 95: y = 2 for all of them, x = 0 to 31

L03 DO Those 32 threads store one number each into C. With j from x: pieces of 32 bytes ____ . With i from x: ____ . Which is correct? ____ . from: L01, L02

CHECK 
j from x: one i, 32 neighbouring numbers, 128 bytes: 4 pieces if they begin at a multiple of
32, 5 if not
i from x: 32 numbers 3,072 * 4 = 12,288 bytes apart: 32 pieces
both are correct: every place of C gets one thread either way; only the cost differs
