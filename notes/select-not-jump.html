An if-else under one instruction

Topics: Lecture 2, CPU. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

An if usually becomes a jump to one side or the other. When one instruction serves 8 indices, a jump would move all 8 together, so it cannot send some indices one way and the rest the other.

The question here: what does the machine execute instead, what keeps the result correct, and what fraction of the work is kept?

Work it out

L01 The slide "SIMD execution requires coherent control" of the Lecture 2 slides of MIT 6.S894 (11 September 2025): 8 ALUs under one instruction, the test x > 0 giving T T F T F F F F, then 3 statements on the if side with ALUs 1, 2 and 4 shaded, and 2 on the else side with the other five shaded. from: the Lecture 2 slides

L02 DO Taking each statement as one step: ALU-steps in the if-else ____ ; shaded ____ ; useful share ____ percent. from: L01

CHECK 
3 * 8 + 2 * 8 = 40 ALU-steps; 3 * 3 + 2 * 5 = 19 shaded; 19 / 40 = 47.5 percent

L03 DO gcc 13.3.0 with -O3 -mavx2 -fno-trapping-math compiles if (x[i] > 0) v = x[i] * 10; else v = 0; into vmulps (x times 10 at all 8 indices), vcmpltps (32 one-bits where 0 < x, zero-bits elsewhere) and vandps. For x = -2, 3, -1, 4, 5, -6, 7, -8, y = ____ . With else v = 5; it uses vblendvps instead; y = ____ . from: L01; gcc 13.3.0 output on the machine that built this site
