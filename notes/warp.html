The 32-thread unit

Topics: GPU chip. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

When a block of threads reaches an SM, the hardware handles its threads in consecutive sets of 32. NVIDIA calls such a set a warp. An instruction begins for all threads of a warp at once, each thread working on its own values.

The question here: when the 32 threads need different numbers of repetitions, what happens to the ones that finish early, and what does it cost?

Work it out

L01 NVIDIA fact: an SM handles a block's threads in consecutive sets of 32 (threads 0 to 31, 32 to 63, and so on), which NVIDIA calls warps. An instruction begins for all threads of a warp at once. from: CUDA programming guide (SIMT architecture)

L02 Your Lab 1 GPU version launches <<<1, 32>>>: 1 block of 32 threads, so 1 warp. For each i, thread t takes the places j = t + 32 x k for k = 0 to 7, and does the Mandelbrot while loop for each. Measured, 256 by 256 picture, max_iters 1000: 1 thread 403.435 ms, 32 threads 17.732 ms. from: your code, your output

L03 From L01, the while loop's instructions keep beginning for the warp until the last of its 32 threads has left the loop; threads already done wait. Name one thread doing one repetition a thread-repetition. Each repetition of the warp costs 32 thread-repetitions; the useful ones add up to the iters. from: L01, L02

L04 DO Real data, i = 40, k = 5 (j = 160 to 191, one place per thread): largest iters 1000, sum of the 32 iters 1,334. Thread-repetitions = 32 x ____ = ____ . Useful = ____ . Useful percent = ____ . from: L03, computation on the lab code

CHECK 
32 x 1000 = 32,000 thread-repetitions
useful 1,334
1,334 / 32,000 = 4.2 percent

L05 DO Real data, all 256 x 8 = 2,048 values of (i, k): useful 16,274,722, thread-repetitions 23,609,216. If only thread-repetitions cost time, 32 threads are faster than 1 by 32 x useful / thread-repetitions = 32 x ____ = ____ . Measured: 403.435 / 17.732 = ____ . from: L02, L03, computation on the lab code

CHECK 
16,274,722 / 23,609,216 = 0.6893
32 x 0.6893 = 22.06 predicted, 22.75 measured
Threads waiting for the slowest thread of their warp explain most of the gap between 32 and 22.75.
