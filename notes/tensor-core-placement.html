Which thread holds which number for a tensor core

Topics: Lab 6, GPU chip. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

A tensor core instruction multiplies whole small matrices, but its inputs and outputs live in the registers of 32 separate threads, each holding a few numbers. Something must decide which thread holds which number.

The question here: who decides it, and what does that change about how a kernel computes its thread numbers and its reads?

Work it out

L01 The Lab 6 handout: the instruction mma.sync.aligned.m16n8k8 with TF32 inputs computes D = A * B + C, A of 16 by 8, B of 8 by 8, C and D of 16 by 8, executed by the 32 threads that NVIDIA calls a warp. NVIDIA's PTX manual: the thread numbered n in its warp, with g = n / 4 rounded down and t = n % 4, holds A(g, t), A(g + 8, t), A(g, t + 4), A(g + 8, t + 4), B(t, g), B(t + 4, g) and C or D at (g, 2t), (g, 2t + 1), (g + 8, 2t), (g + 8, 2t + 1). from: the Lab 6 handout; NVIDIA's PTX manual

L02 DO Thread 13: g = ____ , t = ____ ; it holds A at ____ ; B at ____ ; C at ____ . With A, B and C stored with 8 numbers per line, their places in memory: ____ . from: L01

CHECK 
g = 3, t = 1: A(3, 1), A(11, 1), A(3, 5), A(11, 5); B(1, 3), B(5, 3); C(3, 2), C(3, 3), C(11, 2), C(11, 3)
places 8 * line + place in line: A at 25, 89, 29, 93; B at 11, 43; C at 26, 27, 90, 91

L03 DO D(0, 1) needs A(0, k) and B(k, 1) for k = 0 to 7. Which threads hold them? ____ . Can one thread compute it from its own registers? ____ . from: L01

CHECK 
A(0, k) in threads 0 to 3 (4 * 0 + k % 4); B(k, 1) in threads 4 to 7 (4 * 1 + k % 4)
no: the instruction combines registers of 8 threads, and delivers D(0, 1) to thread 0
