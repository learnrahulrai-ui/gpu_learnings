What the printed difference can hide

Topics: measuring. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

Lab 2 checks each new version against a reference picture and prints one number: the summed difference of iters over all places, divided by the number of places times max_iters. That one number has to stand for both how many places are wrong and how wrong each one is.

The question here: can a broken version print a smaller number than a correct one?

Work it out

L01 The Lab 2 starter's check divides the summed absolute difference of iters by 1024 x 1024 x 2000 (places times max_iters). from: Lab 2 starter code, mandelbrot_cpu_2.cpp

L02 DO Divisor = ____ . A version with a single place wrong by 1 prints 1 / divisor = ____ . from: L01

CHECK 
2,097,152,000
1 / 2,097,152,000 = 0.000000000477: not zero, and one place is wrong

L03 Real data, computed in 32-bit fractions: writing line B of the loop as w - x2 - y2 + cy instead of the starter's w - (x2 + y2) + cy changes iters at 249,479 places, total difference 15,852,362; the two forms are equal in exact arithmetic, so this is rounding only. A version that forgets the cheapest value of i leaves its 1024 places at 0, total difference 93,904. from: computation on the starter's constants

L04 DO Printed number for the rounding change = 15,852,362 / ____ = ____ . For the missing line = 93,904 / ____ = ____ . Which prints the smaller number? ____ , by ____ times. from: L02, L03

CHECK 
rounding change: 0.00756
missing line:    0.0000448
the broken version prints the smaller number, about 169 times smaller

Record instead: the number of places that differ, the first (i, j) that differs, and the largest
difference. With the reference's own line forms, accept only exactly 0.
