SIMD on the CPU: 8 places in one AVX2 instruction

Topics: CPU. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

SIMD means single instruction, multiple data: one instruction acts on several values at once. The Ryzen 5 4600H has AVX2 instructions that act on 256 bits, which is 8 floats of 32 bits, so Lab 1's vector version puts 8 neighbouring places (same i, j to j + 7) into one variable, at index 0 to 7.

Every instruction acts on all 8 indexes, but each place wants its own number of repetitions. The question here: what does that conflict cost, and what decides the cost?

Work it out

L01 Your machine, 256 by 256 picture, max_iters 1000, one core: plain code 61.6 ms, AVX2 code 8.71 ms. from: your output

L02 The vector while loop keeps repeating until all 8 indexes have left, or until 1000 repetitions. Name one index doing one repetition an index-repetition. Each repetition costs 8 index-repetitions; the useful ones, which change some iters, add up to the iters of the 8 places. from: your code

L03 DO Real block, i = 22, j = 184 to 191, iters 7, 8, 10, 15, 154, 1000, 13, 10. Repetitions of the vector loop = ____ . Index-repetitions = ____ . Useful = ____ . Useful percent = ____ . from: L02, computation on the lab code

CHECK 
repetitions = 1000 (index 5 never leaves; iter < 1000 ends the loop)
index-repetitions = 8 x 1000 = 8000
useful = 7 + 8 + 10 + 15 + 154 + 1000 + 13 + 10 = 1217
1217 / 8000 = 15.2 percent

L04 Real data for all 8,192 blocks of 8 neighbours in the picture: 16,274,722 useful out of 18,321,656 index-repetitions. The same count with the 65,536 places shuffled at random before cutting them into blocks of 8: 27.9 percent useful. from: computation on the lab code

L05 DO If only index-repetitions cost time, AVX2 is faster than plain code by 8 x useful share. Neighbours: 8 x ____ = ____ . Shuffled: 8 x 0.279 = ____ . Measured: 61.6 / 8.71 = ____ . from: L01, L02, L04

CHECK 
neighbours: 16,274,722 / 18,321,656 = 0.8883, 8 x 0.8883 = 7.11
shuffled:   8 x 0.279 = 2.23
measured:   61.6 / 8.71 = 7.07

Same instructions, same machine: only which 8 places share a variable changed.
Neighbouring places usually need similar numbers of repetitions, so most blocks finish together;
L03's block sits on the edge of the set and wastes 85 percent. The 7 times comes from the picture.
