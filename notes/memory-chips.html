Which memory chip holds an address

Topics: Lecture 3, memory. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

The memory of a graphics card is several chips, each with its own connection, and its quoted speed is all of them delivering at once. A program sees one long list of addresses, so some rule must say which chip holds which address.

The question here: which rule lets the neighbouring addresses of one instruction use every chip, and what then sets the time?

Work it out

L01 The Lecture 3 slides of MIT 6.S894 (18 September 2025): a GDDR6 chip has a 32-bit interface at 18 billion transfers a second, 72 GB/s; the course GPU has 5 of them, 360 GB/s. The slides give a pair of rules that map addresses to chips: divide (each chip holds one unbroken piece of 4 GB) and mod (the chips take turns, one small piece each). The 32 execution units under one instruction read 128 bytes of neighbouring elements per cycle. from: the Lecture 3 slides

L02 DO Divide rule: chips that serve the 128 bytes ____ ; transfers one after another ____ . Mod rule over the 5 chips with pieces of 4 bytes: floats on each chip ____ ; transfer times ____ . from: L01

CHECK 
divide: 1 chip, 128 / 4 = 32 transfers one after another while 4 chips do nothing
mod: 7, 7, 6, 6, 6 floats; the busiest chip sets the time: 7 transfer times, 4.6 times sooner

L03 DO With the mod rule, the 32 threads read floats 0, 5, 10, ..., 155. Chips that serve them: ____ . from: L01, L02

CHECK 
every float 5k goes to chip 5k mod 5 = 0: one chip, 32 transfers; a step that is a multiple
of the number of chips undoes the mod rule
