Separate buffers and a launch per step

Topics: Lab 3, splitting work. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

Lab 3's wave simulation updates every cell of a grid at once, writing each cell's next height into the same array that holds its previous height, while thousands of threads read the grid.

The question here: what must be true of the reads and writes for the result to be exact, and what separates one step from the next?

Work it out

L01 From the Lab 3 starter: each ordinary cell's next height reads u0[idx] (its own previous height) and u1 at idx, idx - 1, idx + 1, idx - n_cells_x and idx + n_cells_x, then writes u0[idx]; u0 and u1 come from separate cudaMalloc calls. The handout: kernel launches issued one after another finish one before the next begins. from: the Lab 3 starter code and handout

L02 DO Does any thread read a place in u0 that another thread writes in the same step? ____ . Does any thread write u1? ____ . So is overwriting u0 during the step a race? ____ . from: L01

CHECK 
no: each thread reads only its own place in u0, before writing it; no thread writes u1;
so no race: one writer per place, and every shared height comes from u1

L03 DO Why can't a single launch compute two steps? ____ . from: L01, L02

CHECK 
step n + 1 of a cell needs step n of its neighbours, written by other threads, possibly in
other blocks; only the end of a launch guarantees that every cell's step n is written
