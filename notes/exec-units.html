What a count of exec units limits

Topics: Lecture 2, CPU, GPU chip. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

Lecture 2 counts exec units: circuits that each work on one 32-bit number per cycle. A core of the course CPU has 16 of them, and a scheduler of the course GPU 32, one for each of the 32 threads that share an instruction.

The question here: do those counts limit how many numbers a program can hold, or something else?

Work it out

L01 The Lecture 2 slides of MIT 6.S894 (11 September 2025): one Zen 4 core of the course CPU has "Two 256-bit vector ALUs = 16 x 32-bit exec. units" and 192 vector registers; one scheduler of the course GPU has 32 x 32-bit exec units and begins one instruction for 32 threads per clock. On the laptop, Agner Fog's tables give Zen 2 two 256-bit vector float adds begun per cycle, and NVIDIA's Turing tuning guide gives a GTX 1650 SM 4 schedulers of 16 FP32 units each. from: the Lecture 2 slides; Agner Fog's instruction tables; the Turing tuning guide

L02 DO CPU: float additions begun per cycle on one Zen 2 core: 2 * 8 = ____ . A function with 20 __m256 sums compiled with gcc 13.3.0 kept ____ of them in ymm1 to ymm15 and the other ____ on the stack. Bytes for 1,000 __m256 variables: ____ . from: L01; gcc 13.3.0 output on the machine that built this site

CHECK 
16 float additions per cycle, in 2 vector instructions
15 sums in registers, 5 on the stack, each costing a load and a store per repetition
1,000 * 32 = 32,000 bytes: the number of variables is limited by memory

L03 DO GPU: 32 threads each computing 15 independent sums need ____ instructions; on the laptop's 16 units each takes 32 / 16 = ____ cycles to begin, ____ cycles in all. Registers per thread with 8 sets of 32 threads on a laptop scheduler (32 sets per SM / 4 schedulers): 65,536 / 4 / 256 = ____ . from: L01; the CUDA programming guide (65,536 registers per SM, 32 sets of 32 threads per SM)

CHECK 
15 instructions, 2 cycles each, 30 cycles; 64 registers per thread, the rest in memory
an exec unit count limits operations begun per clock, not how many numbers a thread holds
