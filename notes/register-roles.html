What each register of a loop holds

Topics: Lecture 2, CPU. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

A loop names registers but never says what they hold or how big their numbers are. All the code gives is which instructions write each register and how.

The question here: which facts in the Lecture 2 loop decide that r0 holds an address, r2 a distance into the data and r5 a total?

Work it out

L01 The loop of the Lecture 2 slides of MIT 6.S894 (11 September 2025): ld r3, mem[r0+r2], ld r4, mem[r1+r2], mul r3, r3, r4, add r5, r5, r3, addi r2, r2, 4, blt r2, $400, LOOP, and once the loop is left st addr[r6], r5. In ld r3, mem[r0+r2] the value read from memory can only go into r3, and in addi r2, r2, 4 the sum can only go into r2, so the first name of each instruction receives the result. from: the Lecture 2 slides

L02 DO Which registers does an instruction inside the loop write? r0 ____ , r1 ____ , r2 ____ , r3 ____ , r4 ____ , r5 ____ , r6 ____ . from: L01

CHECK 
r0, r1, r6: nothing writes them: fixed addresses
r2: addi, + 4 each iteration, compared with 400 by blt: how far into the data
r3, r4: written by the loads before any read: this iteration's values (r3 then its product)
r5: add, which reads r5 itself: the total so far

L03 DO With r0 = 1000, r1 = 2000 and r2 = 0 when the loop begins (assumed; the slide does not show the instructions before it), which addresses do iterations 1, 2 and 100 read? ____ . If each value took 8 bytes, which bytes would iterations 1 and 2 share? ____ . from: L01, L02

CHECK 
iteration 1: 1000 and 2000; iteration 2: 1004 and 2004; iteration 100: 1396 and 2396
8-byte values: 1000..1007 and 1004..1011 would share 1004..1007, half of one value and half
of the next; so the 4 of addi is the size of one value, and r2 counts bytes, not iterations

L04 DO Put the first list at r0 = 200 instead. In which iterations is r2 then the larger number? ____ . Does any register's role change? ____ . from: L02, L03

CHECK 
r2 = 4 * (k - 1) is above 200 from iteration 52 (r2 = 204) to 100 (r2 = 396)
no role changes: no instruction treats a register differently for holding a large number
