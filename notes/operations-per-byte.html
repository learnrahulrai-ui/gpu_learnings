Operations per byte

Topics: memory. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

A program moves bytes between the graphics card's memory and the chip, and does arithmetic on them. Whichever takes longer sets the time. Dividing the arithmetic a program does by the bytes it moves, and comparing that with what the hardware can do per byte, says which one it is before anything is measured.

The question here: for the first program of every GPU tutorial, adding two arrays, which one sets the time, and by how much?

Work it out

L01 Adding two arrays of n = 16,777,216 floats into a third: for each place k, read a[k] (4 bytes), read b[k] (4 bytes), write c[k] (4 bytes), and do one add. from: code (the standard tutorial program)

L02 GTX 1650 published figures: a 128-bit memory bus, 16 bytes per transfer; with GDDR5 at 8 billion transfers per second, 128 billion bytes per second. The chip has 896 FP32 units, each beginning one add per cycle; this note assumes 1.5 billion cycles per second. from: NVIDIA specifications, assumption

L03 DO Bytes moved = 12 x 16,777,216 = ____ . Adds per byte = ____ . Memory time = ____ ms. Add time = 16,777,216 / (896 x 1.5 billion) = ____ ms. Ratio = ____ . from: L01, L02

CHECK 
201,326,592 bytes
1 / 12 = 0.083 adds per byte
201,326,592 / 128e9 = 1.573 ms
16,777,216 / 1.344e12 = 0.0125 ms
1.573 / 0.0125 = 126

L04 DO Adds the GPU can do per byte its memory moves = 896 x 1.5 billion / 128 billion = ____ . This program does ____ . Would 8-at-once instructions or twice the threads shorten the time? ____ . from: L02, L03

CHECK 
1.344e12 / 128e9 = 10.5 adds per byte needed to keep the units busy
this program: 0.083, about 126 times too few
no: neither moves fewer bytes. What helps: fewer bytes (16-bit numbers halve them),
or more arithmetic on each number while it is on the chip.

L05 DO Measure your own: time the kernel alone (for example nsys profile --stats=true ./add) = ____ ms. Nearer 1.573 or 0.0125? ____ . from: L03, your machine

CHECK 
If moving bytes sets the time, expect between 1.05 ms (GDDR6, 192 billion bytes per second)
and 1.57 ms, plus a little. This note has no measurement from the learner's laptop; yours is the first.
