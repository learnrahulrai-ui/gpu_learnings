A program counter for every thread

Topics: GPU chip. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

A program counter is the address of the next instruction a thread will execute. NVIDIA GPUs from Volta onward, which includes the GTX 1650, give every thread its own program counter, so the threads of one set of 32 may sit at different instructions.

The learner's question: then is the 32-thread unit useless?

Work it out

L01 NVIDIA facts: an SM handles threads in consecutive sets of 32, which NVIDIA calls warps. A warp begins a single instruction at a time, for those of its threads whose program counter is at that instruction. From Volta onward, including your Turing GTX 1650, every thread keeps its own program counter. from: CUDA programming guide (SIMT architecture, Independent Thread Scheduling)

L02 DO Each thread of a warp has 100 instructions of work. All 32 program counters equal at every instruction: instructions that begin = ____ . All 32 different at every instruction: ____ . from: L01

CHECK 
equal: 100 instructions, each for 32 threads
all different: 32 x 100 = 3,200 instructions, each for 1 thread
Per-thread program counters make the second case correct; equal ones make the first 32 times cheaper.

L03 DO A branch: the if side is 10 instructions, the else side 2. Name one thread doing one instruction a thread-instruction; each instruction that begins has room for 32 of them. If 31 threads take the if side and 1 takes the else side: instructions begun = ____ , useful thread-instructions = ____ of ____ . If 1 takes the if side and 31 the else side: begun = ____ , useful = ____ of ____ . from: L01, L02

CHECK 
31 / 1: 12 begun (10 + 2), useful 31 x 10 + 1 x 2 = 312 of 384, 81.25 percent
1 / 31: 12 begun, useful 1 x 10 + 31 x 2 = 72 of 384, 18.75 percent
The cost is the sum of the sides that at least one thread takes; the waste is the threads idle
during each side. One thread on the long side makes the other 31 wait through 10 instructions.
