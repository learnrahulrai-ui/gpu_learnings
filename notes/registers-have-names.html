Registers have names, not addresses

Topics: Lecture 5, GPU chip. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

Registers are the fastest storage on the GPU, and every thread has its own. Yet a program cannot pick one of them by a number it computes, the way it picks an element of an array in memory.

The question here: why can no computed number choose a register, and what happens to an array that is read that way?

Work it out

L01 The Lecture 5 slides of MIT 6.S894 (2 October 2025): the register file is built from parallel banks, one for each of the 32 threads that execute together, and "no r[3] (or r[i]), only r3"; shared memory has 32 banks and a 32 by 32 crossbar, and moving data between threads' registers takes an explicit shuffle instruction. The Lab 4 handout: an array read at a computed element number is moved to local memory, backed by DRAM. from: the Lecture 5 slides; the Lab 4 handout
