Which loop of a loop nest splits

Topics: Lecture 2, splitting work. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

The matrix multiply of Lecture 2 has three loops, over i, k and j, around one statement that adds a product into an entry of C. The lecturer said the iterations of the j loop are independent and could be spread over cores, and described splitting by i as another way.

The question here: what in the statement says which loop's iterations can execute at the same time, and which loop's cannot?

Work it out

L01 The statement of the Lecture 2 slides of MIT 6.S894 (11 September 2025), inside loops over i, then k, then j: C[i*N + j] += A[i*N + k] * B[k*N + j];. Example for this note, N = 3: A holds 1 to 9 in entries 0 to 8, B holds 1, 0, 2, 0, 1, 0, 3, 0, 1, and C begins at 0. from: the Lecture 2 slides; example data

L02 DO For i = 0 and k = 0, the j iterations write which entries of C? ____ . For i = 0 and j = 0, the k iterations write which? ____ , and C[0] after each k: ____ . from: L01

CHECK 
j = 0, 1, 2 write C[0], C[1], C[2] (adding 1, 0 and 2): different entries
k = 0, 1, 2 all write C[0]: 1, then 1 + 2 * 0 = 1, then 1 + 3 * 3 = 10

L03 DO Let the three k iterations execute at the same time, each reading C[0] = 0 before any writes. Which values can C[0] end with? ____ . from: L02

CHECK 
the last write wins: 1, 0 or 9, never 10
k is the one variable missing from the left side C[i*N + j]: iterations differing only in k
write the same entry and form a chain; iterations differing in j or in i write different
entries and split
