Tiles in shared memory

Topics: memory. A single idea, with a few lines to calculate. Each line uses only the lines above it, and the grey note names its source. Fill every ____ on paper, then open CHECK. Any unfamiliar word: words used on this site.

The idea

Multiplying two tables of numbers uses every value of each table many times. The plain GPU program fetches a value from the graphics card's memory every time it uses it. A tile is a small square piece of a table, copied once into fast storage inside the SM and then used by many threads.

The question here: how far must reuse go before memory stops setting the time, and does a square tile that far fit?

Work it out

L01 Tables A, B and the answer C are 1024 by 1024 floats. The answer at (i, j) adds 1024 products of A at (i, k) and B at (k, j): 1024 x 1024 x 1024 = 1,073,741,824 multiply-adds, 2 operations each. The plain program has one thread per answer, each reading its 1024 values of A and 1024 of B from memory. from: definition, code (the standard tutorial program)

L02 GTX 1650 published figures, with an assumed clock: memory moves 128 billion bytes per second (GDDR5 version); 896 FP32 units each begin one multiply-add per cycle; 1.5 billion cycles per second assumed. from: NVIDIA specifications, assumption

L03 DO Bytes read with no reuse = 1024 x 1024 threads x 2 x 1024 values x 4 bytes = ____ . Operations per byte = 2,147,483,648 / that = ____ . Operations the GPU can do per byte its memory moves = 896 x 2 x 1.5 billion / 128 billion = ____ . from: L01, L02

CHECK 
8,589,934,592 bytes
0.25 operations per byte
2.688e12 / 128e9 = 21 operations per byte needed

L04 Shared memory: storage inside each SM that all threads of a block can read and write, far faster than the graphics card's memory; at most 64 KB per SM on Turing. With tiles, a block of T by T threads copies a T by T square of A and one of B into it, and each copied value is used T times, so the bytes read from memory are divided by T. from: NVIDIA Turing Tuning Guide

L05 DO Operations per byte with T = 16: 0.25 x 16 = ____ . T that reaches the 21 of L03: 0.25 x T = 21, T = ____ . Shared memory for the two squares at that T = 2 x T x T x 4 bytes = ____ bytes = ____ KB. from: L03, L04

CHECK 
T = 16: 4 operations per byte, still about 5 times too few
T = 84
2 x 84 x 84 x 4 = 56,448 bytes = 55.1 KB of the SM's 64 KB
One such block fills the SM's shared memory, so no second block fits beside it.
