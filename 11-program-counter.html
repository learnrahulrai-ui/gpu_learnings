Each line uses only what the lines above it made. The grey note says which line it takes from. Fill every ____ on paper, then open CHECK.

L01 A program counter is the address of the next instruction a thread will execute. After an instruction, it moves to the next address, or to a branch target. from: definition

L02 NVIDIA fact: a launch <<<B, T>>> makes B blocks of T threads each. Your GTX 1650 chip is built from 14 units NVIDIA calls SMs; each block executes on one SM. An SM handles a block's threads in units of 32 consecutive threads. NVIDIA names such a unit a warp; your lab file warp_scheduler.cu is named after it. Threads 0 to 31 of a block form warp 0. from: CUDA programming guide, SIMT architecture

L03 NVIDIA fact: a warp executes one common instruction at a time. Each instruction that begins is for the threads of the warp whose program counter is at that instruction. from: CUDA programming guide, SIMT architecture

L04 NVIDIA fact: from Volta onward, which includes your Turing GTX 1650 (sm_75), every thread keeps its own program counter. NVIDIA calls this Independent Thread Scheduling. from: CUDA programming guide, Volta Independent Thread Scheduling

L05 Take this code in warp 0, with a and b in registers: from: example

0x100:  if (threadIdx.x < 16)  a = a + 1;     // ADD
0x200:  else                   b = b * 2;     // MUL
0x300:  /* both sides continue here */

L06 DO After the if, the program counter of threads 0 to 15 = ____ , of threads 16 to 31 = ____ . From L03, can ADD and MUL begin as one instruction? ____ . from: L01, L03, L04, L05

CHECK 
threads 0..15  -> 0x100 (ADD)
threads 16..31 -> 0x200 (MUL)
no: one instruction at a time. ADD begins for 0..15, then MUL begins for 16..31 (or MUL first).

No PC went backward. Two PCs held two different values for a while: that is L04.

L09 DO Your question: if PCs are per thread, why keep the 32-thread unit? Case 1: all 32 PCs equal at every instruction, 100 instructions of work each. Instructions that begin = ____ . Per-thread PCs make case 2 legal. The 32-thread unit makes case 1 32 times cheaper.
Not useless: equal PCs are what the speed comes from; per-thread PCs only make unequal ones correct.
