03. The w line: where is the squaring?

Each line uses only what the lines above it made. The grey note says which line it takes from. Fill every ____ on paper, then open CHECK. Under each piece of code, a panel reads it in English line by line. Any unfamiliar word: words used on this site.

The story

The lab code computes the Mandelbrot repetition in a way that does not look like the textbook formula. The textbook squares a pair (a, b) into (a times a minus b times b, 2 times a times b). The lab code never writes 2 times a times b. Instead it keeps an extra number called w and subtracts things from it.

The learner read this and called it nonsense: the lab says square, and then the code subtracts. The learner was right that the code does not match the words. Where did 2 times a times b go? The only tools needed are multiplying out one square by hand and the learner's own remark that i times i is -1.

Then the page asks the question a reviewer should ask about any clever rewrite: what did it save, and what did it cost? Is counting multiplications even the right way to answer it?

Guess first

In plain words

Code that has been tuned often stops looking like the formula it computes. The tuning was done for a reason on some machine at some time, and the reason may not hold on the next machine. Reading such code means recovering the formula first, and then asking which cost the rewrite was trading against.

For a manager: "we optimized it" is a claim about one cost on one machine. Ask which cost, and on which machine.
