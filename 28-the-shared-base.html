28. Lab 3: the shared base, and who reads which float

Each line uses only what the lines above it made. The grey note says which line it takes from. Fill every ____ on paper, then open CHECK. Under each piece of code, a panel reads it in English line by line. Any unfamiliar word: words used on this site.

The story

After seeing that giving each GPU thread its own unbroken stretch of floats scatters the reads of every instruction, the learner had to build the other arrangement of Lab 3's copy kernels, the one in which the threads of an instruction read side by side. A pair of habits got in the way. The first was a picture of indexing as a fixed corner for each worker plus a small step, where the corner belongs to the worker. The second was the count of all threads in the launch, which seemed to fill in every limit in advance and leave nothing for a loop to do.

Then came a surprise. A second correct version copied exactly the same array as the first, and yet a given thread read different floats in each. The learner had assumed that the same array meant the same reads.

If the corner does not belong to the thread, what does it belong to, and what does an output that checks out say about who read what?

In plain words

Threads that move together should take neighbouring items at each moment. The place where each moment begins is something they all agree on, which moment it is, and each one adds its own number. Correct ways of handing out the work can copy the same data while each worker touches different items, and checking the result cannot tell them apart.

For a manager: two programs that give the same result can divide the work completely differently; ask who touches what, not only whether the result matches.

The interviewer's next question

Why does arrangement P need a corner for each block in its base, while arrangement W needs none?

CHECK 
Under P each block walks a region of its own, so the base must say which region: the
block's number times the size of a region, x * blockDim.x floats. Under W all threads walk
one region together, so the instant alone places the base, and the block's number goes
into the small step, as part of the thread's number in the whole launch.
