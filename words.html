Words used on this site

Every technical word on these pages, in plain English, in alphabetical order. Each page also defines the words it needs before using them, so this list is for looking things up, not for reading first.

[a, b)
The whole numbers from a up to b - 1: a is included and b is not, so [0, 171) holds 0 to 170.
addq, cmpq, jne, jg, jbe
x86 machine instructions on 64-bit numbers: addq adds a number to a register, cmpq compares two numbers, and jne, jg and jbe jump to another instruction if that comparison found them not equal, greater, or below or equal.
address
The number that says where a value sits in memory. Memory is a long list of bytes, numbered from 0; an address is one of those numbers.
aligned
Beginning at a multiple of a given size. A read of 128 neighbouring bytes that begins at a multiple of 32 covers 4 pieces of 32 bytes; one that does not covers 5.
ALU (arithmetic logic unit)
A circuit that does one arithmetic or logic operation, such as an add or a compare, on its inputs. In the Lecture 2 slides an ALU is one exec unit for one 32-bit number: the two 256-bit vector ALUs of a Zen 4 core count as 16 of them.
array
Many values of the same kind stored one after another in memory, reached by their place number: out[5] is the value at place 5 of the array out.
auto-vectorization
The compiler turning an ordinary loop into SIMD instructions on its own; gcc 13.3 turns a plain C loop over floats into vmulps, vcmpltps and vandps on 8 floats at a time.
AVX2
A set of instructions in the laptop's Ryzen processor that act on 256 bits at once, which is 8 fractions of 32 bits each.
AVX-512
A larger set of such instructions, acting on 512 bits at once: 16 fractions of 32 bits. The Lab 1 handout targets it; the laptop's Ryzen 5 4600H does not have it.
bands, turns (splitting work)
Ways to split the values of i between n workers. In bands, each worker takes one stretch of consecutive values, the first worker the first n-th of them, the next worker the next n-th; in turns, worker t takes t, t + n, t + 2n and so on.
barrier, __syncthreads()
A point in a kernel where every thread of a block waits until all of them have arrived; CUDA's __syncthreads() is one. NVIDIA's CUDA programming guide allows it in conditional code only when the condition is the same in every thread of the block; otherwise execution may hang or give wrong results.
base clock, boost clock
The clock speeds a chip maker publishes: the base clock is the speed the chip is promised to hold under load, and the boost clock the highest it reaches when temperature and power allow, for a CPU with a single core busy. The laptop's Ryzen 5 4600H has 3.0 GHz and up to 4.0 GHz; NVIDIA gives the GTX 1650 laptop GPU a boost clock between 1,125 and 1,560 MHz, depending on the laptop.
BRA, BSSY, BSYNC, BMOV, BREAK
GPU machine instructions that control where execution goes: BRA jumps to another instruction; BSSY and BSYNC mark where threads that took different paths meet again; BMOV copies the record of which threads are to meet there into or out of a register; BREAK takes threads that leave a loop out of that record.
bit, byte
A bit holds 0 or 1. A byte is 8 bits. A float or a uint32_t takes 32 bits, which is 4 bytes.
bitwise AND
An operation on two bit patterns that gives 1 at each bit where both have 1, and 0 elsewhere. AND with 32 one-bits leaves a float unchanged; AND with 32 zero-bits turns it into 0.0.
block (CUDA)
A set of GPU threads started together. The launch <<<B, T>>> starts B blocks of T threads each. Each block executes on one SM.
border cell, wall, source (Lab 3)
In the Lab 3 wave simulation: cells on the outer edge of the grid, and wall cells, get height 0 each step without reading any neighbour; source cells get a value from the scene; every other cell is updated from its neighbours.
branch, blt
An instruction that may jump to another instruction instead of going on to the next. blt, branch if less than, in the Lecture 2 loop jumps back while r2 is below 400.
CCD
AMD's chip that holds 8 Zen 4 cores; the Lecture 2 slides give the course CPU's as 70 mm².
chain
A list of operations in which each one needs the value of the one before it, so they cannot overlap.
clock read
Copying the GPU's cycle counter (%clock64) into a variable. The difference between two reads is the number of cycles between them, but only for the instructions the machine listing actually places between them.
cache
Small, fast memory that keeps recently read values so a second read of the same value does not go back to the slow memory chips. The program does not control it directly.
CHECK
On this site, the fold-out box under each exercise that holds the worked answer. Open it only after writing your own.
coherent control
Lecture 2's name for all the indices under one instruction taking the same side of every if, so that every ALU's result is kept.
compiler
The program (here g++ for the CPU and nvcc for the GPU) that turns source code into machine instructions. It may reorder instructions when nothing forbids it.
compiler flags: -O3, -march=native, -arch=sm_75, -ccbin, -pthread
Options on the compile line. -O3: optimize fully. -march=native: allow every instruction this CPU has, such as AVX2. -arch=sm_75: make nvcc produce machine instructions for compute capability 7.5. -ccbin: tell nvcc which g++ to use. -pthread: add the POSIX threads library.
-Xptxas -v
An nvcc option that hands -v on to ptxas, the step that turns PTX into machine instructions, so that it prints, for each kernel, how many registers each thread uses.
compute capability
A pair of numbers that names an NVIDIA GPU's generation and what it can execute. The GTX 1650 is 7.5; nvidia-smi --query-gpu=compute_cap --format=csv prints yours.
const __restrict__
A pointer declared const and __restrict__ promises the compiler that the memory is only read during the kernel and reached through no other pointer, which, the Lab 3 handout says, lets the loads be cached in L1.
core
A part of a CPU that executes its own sequence of instructions. The Ryzen 5 4600H has 6. The Lecture 2 slides also call each warp scheduler of the course GPU a core, 192 in all.
CPU
The central processor of a computer, built to finish one sequence of instructions as fast as possible.
CS2R, LDG
GPU machine instructions: LDG copies a value from the graphics card's memory into a register; CS2R copies a special register, such as the cycle counter, into an ordinary one.
cudaMalloc, cudaMemcpy, cudaDeviceSynchronize
CUDA calls made from the CPU: the first reserves memory on the graphics card, the second copies between CPU memory and the graphics card's memory, the third waits until everything sent to the GPU has finished.
cudaGetDeviceProperties, multiProcessorCount
A CUDA call made from the CPU that fills a record describing the GPU; its field multiProcessorCount holds the number of SMs, 14 on the GTX 1650 and 48 on the course GPU.
cudaOccupancyMaxActiveBlocksPerMultiprocessor
A CUDA call made from the CPU that returns how many blocks of a given kernel, at a given number of threads per block, one SM can hold at once.
cuobjdump
A CUDA toolkit program that prints what is inside a compiled GPU program; cuobjdump -sass prints its machine instructions, the listing.
cycle
A single tick of a processor's clock. Times inside the GPU are counted in cycles.
DDR5, HBM3
Kinds of memory chip in Lecture 3: a DDR5 chip with a 32-bit interface at 6.4 GT/s gives 25.6 GB/s; an HBM3 module with a 2048-bit interface at 3.2 GT/s gives 819 GB/s and sits in the same package as the processor.
difference (the starters' check)
The number the Lab 1 and Lab 2 starters print after each version: the sum over all places of the gap between the version's count and the reference's count, divided by img_size times img_size times max_iters. A correct version prints exactly 0.
DRAM
The memory chips. On a graphics card they sit outside the GPU chip, so reading from them takes many cycles.
exec unit (execution unit)
A circuit that carries out one operation on one number per cycle. The Lecture 2 slides count 16 32-bit exec units in a core of the course CPU and 32 in a warp scheduler of the course GPU. The Lecture 3 slides call them EUs.
fat while loop, thin loop
The learner's names: a thin loop carries one set of places in each repetition; a fat while loop carries two or more independent sets in the same repetition and is left only when every set is done, each set's mask still stopping its own counts.
Fetch & Decode, Exec, Program State, State, Shared State
Boxes in the Lecture 2 drawings: Fetch & Decode reads the next instruction and works out what it asks for; Exec carries it out; Program State holds the registers of one stream of instructions; State holds the values a single ALU works on; Shared State holds what all the ALUs under one Fetch & Decode share, such as the address of the next instruction.
FFMA, FADD, FMUL
Names of GPU machine instructions: FFMA multiplies two fractions and adds a third in one step; FADD adds two fractions; FMUL multiplies two.
float
A fraction stored in 32 bits. It can only hold certain values; a typed number becomes the nearest one it can hold.
fmadd (fused multiply-add)
A single instruction that computes a times b plus c. On the CPU, _mm256_fmadd_ps does it at 8 indexes at once.
-fno-trapping-math
A gcc option that lets the compiler assume floating-point operations raise no signal the program watches, such as overflow or division by zero. With it, gcc 13.3 computes both sides of an if-else over floats and keeps one per index; without it, gcc leaves that loop on single floats.
FP32 unit
A circuit in the GPU that does one 32-bit multiply-add for one thread. The GTX 1650 has 896 of them; NVIDIA's specifications call them CUDA cores.
FP32, FP64
Numbers stored in 32 bits (float) and in 64 bits (double). On the GTX 1650 an SM produces 64 FP32 results per clock but only 2 FP64 results, according to NVIDIA's CUDA programming guide.
hardware thread (SMT)
An instruction sequence that a CPU core keeps going alongside others, which AMD calls simultaneous multithreading, SMT. The laptop's cores keep 2 each, sharing the core's arithmetic circuits, so either can begin instructions while the other waits. Intel, and the Lecture 2 slides, call them hyperthreads.
GDDR5, GDDR6
Kinds of memory chips used on graphics cards. GDDR6 moves more bytes per second over the same wires. Lecture 3: a GDDR6 chip has a 32-bit interface at 18 GT/s, 72 GB/s; the course GPU has 5 of them, 360 GB/s.
Geekbench 6
A published set of benchmark programs that measures CPU speed; the Lecture 2 graph of core size against work per clock uses its combined score.
GPU
A graphics processor: thousands of simple arithmetic circuits that are fast when many of them do the same instruction at the same moment.
graph paper
The learner's word for the mathematical plane with (0, 0) at its center, where the middleman pairs live.
GT/s
Billions of transfers per second; each transfer moves one interface's worth of bits, so a 32-bit interface at 18 GT/s moves 4 bytes x 18 billion = 72 GB/s.
image paper
The learner's word for the 256 by 256 sheet of results, the array out, with i counting down and j counting right.
IEEE 754
The standard that fixes how floats are stored and how a result that falls between two floats is rounded.
ILP (instruction-level parallelism)
Independent instructions inside one thread, which the processor can begin while earlier ones still wait for their results. Lab 2, part 1 creates it by giving each loop several independent sets of places.
in order, out of order
A processor can begin instructions in order, each only after the one written before it has begun, or out of order, any instruction whose inputs are ready, while the result stays the same as in order.
independent set (of places)
Places whose arithmetic never needs the values of another set, so that one set's instructions can begin while another set's wait. On the CPU a set is the 8 places of one vector; on the GPU, one place per thread.
index-repetition
On this site: one index of an 8-float AVX2 variable doing one repetition of the loop. A repetition of the vector loop costs 8 of them, useful or not.
index 0 to 7
The place of one of the 8 values held in a 256-bit AVX2 variable.
instruction
A basic step a processor executes: add, multiply, compare, copy, jump.
instruction tables (Agner Fog)
Agner Fog's published measurements of each instruction on each CPU design: how many cycles its result takes and how many can begin per cycle. For Zen 2 they give 3 cycles for a vector float add or multiply, and 2 adds and 2 multiplies begun per cycle.
intrinsic
A function name in C++ that the compiler turns into one specific processor instruction, such as _mm256_add_ps.
_mm256_add_ps, _mm256_fmadd_ps
AVX2 intrinsics for 8 floats at once: add_ps adds 8 floats to 8 others, index by index; fmadd_ps multiplies two sets of 8 and adds a third, rounding once.
_mm256_cmp_ps, _mm256_testz_ps
cmp_ps compares 8 floats with 8 others, index by index, and puts 32 bits all 1 where the comparison holds and 32 bits all 0 elsewhere; testz_ps(a, a) gives 1 when the top bit of each of the 8 pieces of a is 0.
_mm256_castps_si256, _mm256_sub_epi32
castps_si256 reads the same 256 bits as 8 32-bit whole numbers without changing them; sub_epi32 subtracts 8 whole numbers from 8 others, index by index.
_mm256_set1_ps, _mm256_set_ps, _mm256_setr_ps, _mm256_setzero_si256
Ways to make a vector: set1_ps puts one float at all 8 indexes; set_ps takes 8 floats with the one for index 7 first; setr_ps takes them with index 0 first; setzero_si256 makes 256 bits of 0.
_mm256_store_si256, _mm256_storeu_si256
Write 256 bits to memory: store_si256 needs an address that is a multiple of 32; storeu_si256 takes any address.
ISA (instruction set)
The list of instructions a processor accepts. AVX2 and AVX-512 belong to the x86 instruction set of Intel and AMD processors; NEON belongs to ARM's.
iso-process
Compared as if every chip were built with the same transistor size, so that more area means more transistors.
iteration
A single repetition of a loop's body.
iters
The number of repetitions the Mandelbrot loop did for one place before leaving; this is what the picture stores.
kernel
A function that executes on the GPU, marked __global__ in CUDA.
KiB, MiB
A KiB is 1,024 bytes and a MiB is 1,048,576 bytes. The laptop's hardware audit lists 192 KiB of L1 data cache in all.
L1, L2, L3 cache
Caches in levels, from the smallest and fastest, L1, next to each core, to the largest, L3, shared by the cores. The laptop's hardware audit lists L1d 192 KiB (32 KiB per core), L2 3 MiB and L3 8 MiB; the Lecture 2 slides give the course CPU 1 MB of L2 per core and 32 MB of L3.
listing
The machine instructions the compiler actually produced, printed with cuobjdump -sass. It shows the real order of instructions.
local memory (CUDA)
The memory that holds a GPU thread's values that do not fit in its registers. It sits in the graphics card's memory, so using it costs loads and stores.
loop nest
Loops written one inside another, such as the loops over i, k and j around the single statement of a matrix multiply.
mask
The result of an AVX2 compare: at each index, 32 bits all 1 where the test was true, all 0 where it was false.
Mandelbrot set
The picture the labs compute. For each point, a short calculation is repeated until the value moves farther than 2 from (0, 0) or a cap of repetitions is reached.
matrix multiply
Computing C from A and B: entry (i, j) of C is the sum, over k, of A's entry (i, k) times B's entry (k, j). With N by N matrices it takes N * N * N multiply-adds.
max_iters
The cap on repetitions, 1000 in the lab measurements on this site.
memory bus
The wires between the GPU chip and its memory chips. On the GTX 1650 it is 128 bits, so 16 bytes move per transfer.
memory channel, striping
Each memory chip with its own connection is a channel. Striping deals addresses out to the channels in small pieces, taking turns (the chip is the address divided by the piece size, mod the number of chips), so neighbouring addresses land on different chips; dealing them out in large unbroken blocks (the address divided by the block size) is the divide rule of Lecture 3.
middleman pair
The learner's word for (cx, cy), the two fractions computed from (i, j) that the Mandelbrot loop actually works on.
normalized
Divided by a reference value, so that the reference becomes 1x.
notes (this site)
The short pages in the notes section: one idea each, a few lines to calculate, and the notes that point to each one.
ncu (Nsight Compute)
NVIDIA's profiler for single kernels, used from the command line as ncu --metrics ... ./program. On many machines it needs administrator rights to read the GPU's counters.
nsys (Nsight Systems)
NVIDIA's tool that times what the CPU and the GPU did, kernel by kernel. nsys profile --stats=true ./program prints the time of each kernel.
nvidia-smi
A program installed with NVIDIA's driver that prints the GPU's name, memory, temperature and clocks; nvidia-smi -q -d CLOCK prints the clocks.
profiler
A tool (here NVIDIA Nsight Compute) that counts what the GPU did, such as memory requests and sectors.
operations per byte
How many arithmetic operations a program does for each byte it moves to or from memory. Below what the hardware needs to stay busy, memory sets the time.
operations per second (FLOP/s)
Arithmetic operations completed per second. A multiply-add counts as 2: one multiply and one add.
outside part (this site)
The cycles of a timing that the timed operations do not explain: measured cycles minus (number of operations - 1) times the cycles per operation. Equal only between two lengths of the same kernel.
owner
On this site: the worker (CPU thread or GPU thread) responsible for writing a given place of the output. A correct split gives every place exactly one owner.
median
The middle value of a list once it is sorted. Of 10, 10, 11, 14, 30 it is 11.
PCIe
PCI Express, the connection between the computer's CPU side and a graphics card; the course machine's PCIe 4.0 moves 32 GB/s.
physical register, logical register
A logical register is a name a program uses, such as r3 or ymm0; a physical register is a storage cell in the chip. The lecturer's simple processor has one physical register for each logical register.
predication
An instruction that is executed for every thread but has effect only where a stated condition is true, so no jump is needed. Shown in a listing with a prefix such as @!P2.
PTX
The instruction language NVIDIA defines for its GPUs, one step above the machine instructions that nvcc finally produces. Code can insert a PTX instruction by hand with asm volatile, as the clock read of the Lab 2 prelab does with mov.u64.
program counter
The address of the next instruction a thread will execute.
POSIX threads (pthreads)
The standard library of thread functions on Linux and other Unix systems, such as pthread_create and pthread_join; g++ needs -pthread to use it.
pthread_create, pthread_join
CPU library calls: the first starts a new thread executing a given function; the second waits until that thread has finished.
race
Threads touching the same place in the same step, at least one of them writing, so that the result depends on which goes first.
Raptor Cove, Core 2 Duo, Pentium Pro
Intel CPU core designs named in Lecture 2: Raptor Cove is the largest core on the slide's graph, and the Core 2 Duo and the Pentium Pro are older ones the lecturer compared.
rax, rcx, rdx, rdi, rsi, rsp
x86 registers of 64 bits that hold one number each, such as a counter or an address; rsp holds the address of the stack.
reduction
Turning many numbers into one, such as adding up an array. The work is easy to split; the dependence between partial results is the hard part.
register
A small storage cell inside the processor chip. Arithmetic reads its inputs only from registers.
register budget
On a Turing SM, 65,536 registers shared by every thread it holds; at 1,024 threads that is 64 per thread. The compiler reports a kernel's use with -Xptxas -v.
register renaming
Keeping several physical registers for one register name, so that an instruction can write a new value while earlier instructions still need the old one. Each Zen 4 core has 192 vector registers behind the 32 names AVX-512 gives a program.
repetition
A single trip through the lines inside a loop.
request, sector (profiler)
Words of the Nsight Compute profiler: a request is one memory instruction for the 32 threads of a warp; a sector is a 32-byte block of memory that the instruction touches.
RTX 4000 Ada (AD104)
The course machine's GPU: 48 SMs of 4 warp schedulers each, every scheduler with 32 FP32 exec units, at 2.175 GHz, as the Lecture 2 slides give it.
Ryzen 7 7700, Zen 4
The course machine's CPU: 8 Zen 4 cores, each with two 256-bit vector ALUs (16 32-bit exec units), 192 vector registers, 1 MB of L2 cache and 2 hardware threads, as the Lecture 2 slides give it.
scoreboard
A record inside the GPU of registers still waiting for a value; an instruction that needs one of them is held until it arrives.
shared memory
Storage inside each SM that all threads of one block can read and write, much faster than the graphics card's memory chips. At most 64 KB per SM on Turing.
significant bits
The bits of a float that hold its digits, as opposed to the bits that say how large it is. A float has 24, so above 16,777,216 it cannot hold every whole number.
SIMD
Single instruction, multiple data: one instruction acting on several values at once, as AVX2 does with 8. The Lecture 2 slides add that it can be written in the instruction set, as AVX and ARM's NEON are, or be implicit in GPUs.
SM
Each of the identical blocks of hardware an NVIDIA GPU chip is built from. The GTX 1650 has 14, each with 64 FP32 units.
speedup
The time of one version divided by the time of a faster one: a speedup of 4.72 means the faster version takes 4.72 times less time.
stack
The memory a function keeps for its own values; gcc puts there the variables that do not fit in registers.
std::swap
A C++ function that exchanges the values of two variables; in Lab 3 it exchanges the pointers u0 and u1, not the arrays they point to.
telerun
The course's tool for sending code to its own machines. It needs a course account, so self-learners compile and time on their own computer instead.
TFLOPS
10^12 floating-point operations per second, with a multiply-add counted as 2. The Lecture 2 slides give the course GPU 26.7 and the course CPU 0.97 to 1.4.
threadIdx.x, blockIdx.x, blockDim.x
Numbers every GPU thread can read: its own number inside its block, its block's number, and the number of threads per block.
threadIdx.y, blockIdx.y, blockDim.y, gridDim.x, dim3
The y numbers of a launch whose sizes are given as dim3 values, and gridDim.x, the number of blocks across. The x number changes fastest, so threads with consecutive threadIdx.x share a warp.
tile
A small square piece of a large table, copied into shared memory so many threads can use each value without fetching it again.
thread
A sequence of instructions being executed. On a GPU, thousands can exist at once, each with its own values.
thread-instruction, thread-repetition, warp-repetition
On this site: one GPU thread doing one instruction, or one repetition of a loop; and one repetition of the loop by a whole warp of 32 threads. An instruction that begins for a warp has room for 32 thread-instructions, whether or not every thread has work.
transistor
The tiny electrical switch that chips are built from. The Lecture 2 graph measures a core's size in transistors, as if every core were built with the same transistor size.
Turing, Volta, Ada
Names of NVIDIA GPU generations. The GTX 1650 is Turing; Volta came just before it; the course GPU, an RTX 4000 Ada, is a later generation.
u0, u1 (Lab 3)
The wave simulation's two grids of heights: u0 holds the previous heights and receives the next ones, u1 holds the present heights; after each step the two pointers are swapped.
vaddps, vmulps, vcmpltps, vandps, vblendvps, vmaskmovps
AVX machine instructions on 8 floats in 256-bit ymm registers: add; multiply; compare less-than, giving a mask; bitwise AND; blend, which takes each index from one of two registers as a mask chooses; and a store that writes only the indices whose mask is all ones.
vmovups, vmovaps, vbroadcastss, vxorps, vcomiss, vmulss
More AVX machine instructions: vmovups and vmovaps copy 8 floats between a register and memory; vbroadcastss copies one float into all 8 indices; vxorps of a register with itself makes 0.0 at every index; vcomiss compares two single floats; vmulss multiplies two single floats.
warp scheduler
A circuit in each SM that, every cycle, picks which warp's next instruction begins. Turing and Ada GPUs have 4 per SM.
wave (second round)
When a launch has more blocks than the SMs can hold at once, the extra blocks wait until earlier ones finish and then execute as a further round.
warp
NVIDIA's name for 32 consecutive threads of a block that the hardware handles together, one instruction at a time.
WSL2
Windows Subsystem for Linux: a Linux system inside Windows, enough to follow the lessons on a Windows laptop.
ymm0 to ymm15, zmm0 to zmm31, __m256
The 16 AVX registers of 256 bits that a program can name in 64-bit mode, the 32 AVX-512 registers of 512 bits, and the C++ type that holds 8 floats in a ymm register.
Zen 2
AMD's CPU design used in the Ryzen 5 4600H. Published figures: an add or multiply that needs the previous result waits 3 cycles.
