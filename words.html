Words used on this site

Every technical word on these pages, in plain English, in alphabetical order. Each page also defines the words it needs before using them, so this list is for looking things up, not for reading first.

address
The number that says where a value sits in memory. Memory is a long list of bytes, numbered from 0; an address is one of those numbers.
array
Many values of the same kind stored one after another in memory, reached by their place number: out[5] is the value at place 5 of the array out.
AVX2
A set of instructions in the laptop's Ryzen processor that act on 256 bits at once, which is 8 fractions of 32 bits each.
AVX-512
A larger set of such instructions, acting on 512 bits at once: 16 fractions of 32 bits. The Lab 1 handout targets it; the laptop's Ryzen 5 4600H does not have it.
BRA, BSSY, BSYNC
GPU machine instructions that control where execution goes: BRA jumps to another instruction; BSSY and BSYNC mark where threads that took different paths meet again.
bit, byte
A bit holds 0 or 1. A byte is 8 bits. A float or a uint32_t takes 32 bits, which is 4 bytes.
block (CUDA)
A set of GPU threads started together. The launch <<<B, T>>> starts B blocks of T threads each. Each block executes on one SM.
chain
A list of operations in which each one needs the value of the one before it, so they cannot overlap.
clock read
Copying the GPU's cycle counter (%clock64) into a variable. The difference between two reads is the number of cycles between them, but only for the instructions the machine listing actually places between them.
cache
Small, fast memory that keeps recently read values so a second read of the same value does not go back to the slow memory chips. The program does not control it directly.
CHECK
On this site, the fold-out box under each exercise that holds the worked answer. Open it only after writing your own.
compiler
The program (here g++ for the CPU and nvcc for the GPU) that turns source code into machine instructions. It may reorder instructions when nothing forbids it.
compiler flags: -O3, -march=native, -arch=sm_75, -ccbin, -pthread
Options on the compile line. -O3: optimize fully. -march=native: allow every instruction this CPU has, such as AVX2. -arch=sm_75: make nvcc produce machine instructions for compute capability 7.5. -ccbin: tell nvcc which g++ to use. -pthread: add the POSIX threads library.
compute capability
A pair of numbers that names an NVIDIA GPU's generation and what it can execute. The GTX 1650 is 7.5; nvidia-smi --query-gpu=compute_cap --format=csv prints yours.
core
A part of a CPU that executes its own sequence of instructions. The Ryzen 5 4600H has 6.
CPU
The central processor of a computer, built to finish one sequence of instructions as fast as possible.
CS2R, LDG
GPU machine instructions: LDG copies a value from the graphics card's memory into a register; CS2R copies a special register, such as the cycle counter, into an ordinary one.
cudaMalloc, cudaMemcpy, cudaDeviceSynchronize
CUDA calls made from the CPU: the first reserves memory on the graphics card, the second copies between CPU memory and the graphics card's memory, the third waits until everything sent to the GPU has finished.
cycle
A single tick of a processor's clock. Times inside the GPU are counted in cycles.
DRAM
The memory chips. On a graphics card they sit outside the GPU chip, so reading from them takes many cycles.
FFMA, FADD, FMUL
Names of GPU machine instructions: FFMA multiplies two fractions and adds a third in one step; FADD adds two fractions; FMUL multiplies two.
float
A fraction stored in 32 bits. It can only hold certain values; a typed number becomes the nearest one it can hold.
fmadd (fused multiply-add)
A single instruction that computes a times b plus c. On the CPU, _mm256_fmadd_ps does it at 8 indexes at once.
FP32 unit
A circuit in the GPU that does one 32-bit multiply-add for one thread. The GTX 1650 has 896 of them.
hardware thread (SMT)
An instruction sequence that a CPU core keeps going alongside others. The laptop's cores keep 2 each, sharing the core's arithmetic circuits, so either can begin instructions while the other waits.
GDDR5, GDDR6
Kinds of memory chips used on graphics cards. GDDR6 moves more bytes per second over the same wires.
GPU
A graphics processor: thousands of simple arithmetic circuits that are fast when many of them do the same instruction at the same moment.
graph paper
The learner's word for the mathematical plane with (0, 0) at its center, where the middleman pairs live.
image paper
The learner's word for the 256 by 256 sheet of results, the array out, with i counting down and j counting right.
IEEE 754
The standard that fixes how floats are stored and how a result that falls between two floats is rounded.
ILP (instruction-level parallelism)
Independent instructions inside one thread, which the processor can begin while earlier ones still wait for their results. Lab 2, part 1 creates it by giving each loop several independent sets of places.
index-repetition
On this site: one index of an 8-float AVX2 variable doing one repetition of the loop. A repetition of the vector loop costs 8 of them, useful or not.
index 0 to 7
The place of one of the 8 values held in a 256-bit AVX2 variable.
instruction
A basic step a processor executes: add, multiply, compare, copy, jump.
intrinsic
A function name in C++ that the compiler turns into one specific processor instruction, such as _mm256_add_ps.
iters
The number of repetitions the Mandelbrot loop did for one place before leaving; this is what the picture stores.
kernel
A function that executes on the GPU, marked __global__ in CUDA.
listing
The machine instructions the compiler actually produced, printed with cuobjdump -sass. It shows the real order of instructions.
mask
The result of an AVX2 compare: at each index, 32 bits all 1 where the test was true, all 0 where it was false.
Mandelbrot set
The picture the labs compute. For each point, a short calculation is repeated until the value moves farther than 2 from (0, 0) or a cap of repetitions is reached.
max_iters
The cap on repetitions, 1000 in the lab measurements on this site.
memory bus
The wires between the GPU chip and its memory chips. On the GTX 1650 it is 128 bits, so 16 bytes move per transfer.
middleman pair
The learner's word for (cx, cy), the two fractions computed from (i, j) that the Mandelbrot loop actually works on.
notes (this site)
The short pages in the notes section: one idea each, a few lines to calculate, and the notes that point to each one.
ncu (Nsight Compute)
NVIDIA's profiler for single kernels, used from the command line as ncu --metrics ... ./program. On many machines it needs administrator rights to read the GPU's counters.
nsys (Nsight Systems)
NVIDIA's tool that times what the CPU and the GPU did, kernel by kernel. nsys profile --stats=true ./program prints the time of each kernel.
profiler
A tool (here NVIDIA Nsight Compute) that counts what the GPU did, such as memory requests and sectors.
operations per byte
How many arithmetic operations a program does for each byte it moves to or from memory. Below what the hardware needs to stay busy, memory sets the time.
operations per second (FLOP/s)
Arithmetic operations completed per second. A multiply-add counts as 2: one multiply and one add.
outside part (this site)
The cycles of a timing that the timed operations do not explain: measured cycles minus (number of operations - 1) times the cycles per operation. Equal only between two lengths of the same kernel.
owner
On this site: the worker (CPU thread or GPU thread) responsible for writing a given place of the output. A correct split gives every place exactly one owner.
median
The middle value of a list once it is sorted. Of 10, 10, 11, 14, 30 it is 11.
predication
An instruction that is executed for every thread but has effect only where a stated condition is true, so no jump is needed. Shown in a listing with a prefix such as @!P2.
program counter
The address of the next instruction a thread will execute.
pthread_create, pthread_join
CPU library calls: the first starts a new thread executing a given function; the second waits until that thread has finished.
reduction
Turning many numbers into one, such as adding up an array. The work is easy to split; the dependence between partial results is the hard part.
register
A small storage cell inside the processor chip. Arithmetic reads its inputs only from registers.
register budget
On a Turing SM, 65,536 registers shared by every thread it holds; at 1,024 threads that is 64 per thread. The compiler reports a kernel's use with -Xptxas -v.
repetition
A single trip through the lines inside a loop.
request, sector (profiler)
Words of the Nsight Compute profiler: a request is one memory instruction for the 32 threads of a warp; a sector is a 32-byte block of memory that the instruction touches.
scoreboard
A record inside the GPU of registers still waiting for a value; an instruction that needs one of them is held until it arrives.
shared memory
Storage inside each SM that all threads of one block can read and write, much faster than the graphics card's memory chips. At most 64 KB per SM on Turing.
significant bits
The bits of a float that hold its digits, as opposed to the bits that say how large it is. A float has 24, so above 16,777,216 it cannot hold every whole number.
SIMD
Single instruction, multiple data: one instruction acting on several values at once, as AVX2 does with 8.
SM
Each of the identical blocks of hardware an NVIDIA GPU chip is built from. The GTX 1650 has 14, each with 64 FP32 units.
telerun
The course's tool for sending code to its own machines. It needs a course account, so self-learners compile and time on their own computer instead.
threadIdx.x, blockIdx.x, blockDim.x
Numbers every GPU thread can read: its own number inside its block, its block's number, and the number of threads per block.
tile
A small square piece of a large table, copied into shared memory so many threads can use each value without fetching it again.
thread
A sequence of instructions being executed. On a GPU, thousands can exist at once, each with its own values.
thread-instruction, thread-repetition, warp-repetition
On this site: one GPU thread doing one instruction, or one repetition of a loop; and one repetition of the loop by a whole warp of 32 threads. An instruction that begins for a warp has room for 32 thread-instructions, whether or not every thread has work.
Turing, Volta, Ada
Names of NVIDIA GPU generations. The GTX 1650 is Turing; Volta came just before it; the course GPU, an RTX 4000 Ada, is a later generation.
warp scheduler
A circuit in each SM that, every cycle, picks which warp's next instruction begins. Turing and Ada GPUs have 4 per SM.
wave (second round)
When a launch has more blocks than the SMs can hold at once, the extra blocks wait until earlier ones finish and then execute as a further round.
warp
NVIDIA's name for 32 consecutive threads of a block that the hardware handles together, one instruction at a time.
WSL2
Windows Subsystem for Linux: a Linux system inside Windows, enough to follow the lessons on a Windows laptop.
Zen 2
AMD's CPU design used in the Ryzen 5 4600H. Published figures: an add or multiply that needs the previous result waits 3 cycles.
