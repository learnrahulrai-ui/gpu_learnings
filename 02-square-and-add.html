02. Square and add: the counting loop by hand

Pencil. Paper. Every blank ____ is yours. Open CHECK only after you wrote a number.

Start from zero

From page 01: one grid square (i, j) of the 256 x 256 output becomes one spot (cx, cy) through cx = j/256*2.5 - 2.0 and cy = i/256*2.5 - 1.25. Now the count for that spot. A moving pair (x, y) starts at (0, 0). One pass = square the moving pair, then add (cx, cy) to it. Before every pass, test x*x + y*y. If it is above 4, stop. The count is the number of passes done. The cap is 1000 passes.

squaring a pair (a, b):

        new first  = a*a - b*b
        new second = 2*a*b

one pass:   (x, y)  -->  (x*x - y*y + cx ,  2*x*y + cy)
test before each pass:   x*x + y*y <= 4 ?   yes -> do the pass, count + 1
                                            no  -> stop, write count

Where you got stuck

"if i start at 00 squaring means nothing there shall be no change at all ever" / "whyy would i start form 00 when i alreadyyy started with 1 0" / "you are asking for square and then doing substractioon" / "A point 9 7 is going to be at 9 7. There is no escaping."

Step 1: the spot never moves, the moving pair does

Two pairs exist. (cx, cy) is fixed for the whole loop: it is the spot from page 01. (x, y) is a second pair that starts at (0, 0) and changes every pass. Squaring (0, 0) gives (0, 0), and then adding (cx, cy) gives (cx, cy). So pass 1 always lands on the spot itself. Pass 2 is where squaring starts to do work.

            fixed                       moving
         +----------+              +------------------+
         | (cx, cy) | --- added -->| (x, y)           |
         +----------+  every pass  | start (0, 0)     |
                                   | pass 1 -> (cx,cy)|
                                   | pass 2 -> ?      |
                                   +------------------+
DO: Square (2, 1) with the rule. New first = ____ . New second = ____ .
CHECK 
2*2 - 1*1 = 3
2*2*1     = 4
(2, 1) squared = (3, 4)

Step 5: why 4 and not 2

The test compares x*x + y*y with 4. The distance of (x, y) from (0, 0) is the square root of x*x + y*y. Distance above 2 means x*x + y*y above 2*2 = 4. Comparing with 4 avoids the square root on every pass.

DO: Pass-4 pair from step 3 is (-2.555664, -0.351562). Distance = square root of ____ = ____ . Above 2? ____ .
CHECK 
x*x + y*y = 6.655015
square root = 2.5797...  > 2   same verdict as 6.655015 > 4
